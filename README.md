# Электробезопасность — тестирование по билетам

PWA без сборки на стороне сервера: 10 билетов по 10 вопросов, работает офлайн. Варианты ответов каждый раз перемешиваются; «Все ответы неверны», «Все перечисленные…» остаются в конце.

## Структура

- `index.html`, `js/app.js` — интерфейс и логика
- `data/exam_data.json` — **единственный** источник вопросов (поля: `question`, `options`, `correct` — номер верного варианта с нуля, `explanation`)
- `css/tailwind.css` — **готовая** сборка стилей (в репозитории, пересобирать нужно только при смене классов)
- `sw.js` — service worker (офлайн-кэш). Код и данные берутся «сначала из сети», а шрифт, картинки и иконки — из кэша: если меняете такой файл, увеличьте `CACHE`, иначе у посетителей останется старая версия

## Пересборка стилей

После правок классов Tailwind в `index.html` или `js/app.js`:

```bash
npx tailwindcss@3 -c tailwind.config.js -i src/input.css -o css/tailwind.css --minify
```

## Локальный запуск

```bash
python3 -m http.server 8000   # затем http://localhost:8000
```
